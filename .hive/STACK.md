## Architecture Pattern
Backend: Domain-Driven Design (DDD) with 4 layers
- Domain → Entities, Value Objects, Aggregates, Domain Events
- Application → Services (orchestration), Validators
- Infrastructure → Prisma repositories, external adapters
- Presentation → Express controllers, routes

Frontend: Component-based with service layer (shadcn/ui + Tailwind)
- `src/frontend/src/services/` → all API calls (never axios directly in components)
- `src/frontend/src/components/` → shadcn components + custom feature components
- `src/frontend/src/pages/` → route-level components (orchestrate only)
- `src/frontend/src/hooks/` → custom hooks for reusable stateful logic
- `src/frontend/src/types/` → TypeScript domain and API types
- `src/frontend/src/constants/` → ROUTES, STATUS_VALUES, API_BASE_URL
